## A–F

**Async** — a keyword marking a function that returns a Promise and can use `await` inside. [→ async-await](./async-await.md)

**Await** — pauses execution inside an `async` function until a Promise resolves.

**Closure** — a function that remembers variables from the scope it was created in, even after that scope has exited.

---

## G–L

**Hoisting** — JavaScript's behavior of moving declarations to the top of their scope before code runs.

---

## M–R

**Promise** — an object representing a value that will exist later; has three states: pending, fulfilled, rejected. [→ promises](./promises.md)

---

## S–Z

**Scope** — the region of code where a variable is accessible.

**Synchronous** — code that runs one line at a time, blocking until each finishes.

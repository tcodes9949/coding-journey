## What I learned

A variable is a named container that holds a value. A data type describes what kind of value it holds. The data types I've seen so far are `string`, `number`, `boolean`, `null`, and `undefined`.

I also learned the difference between three categories:

- **Keywords** (`let`, `const`, `var`) — words that tell JavaScript to do something, like declare a variable.
- **Operators** (`=`, `===`, `+`, `>`) — symbols that perform an action on values.
- **Data types** — the kind of value a variable holds.

These three are easy to mix up, so I listed them separately.
